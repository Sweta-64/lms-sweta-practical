PROJECT OVERVIEW & DESCRIPTION
================================================================================

The Employee Leave Management System is a complete web-based application that 
allows employees to apply for leaves and enables administrators to manage and 
approve/reject leave requests. The system prevents overlapping leave applications 
automatically.

KEY FEATURES:
  ✓ Employee leave applications with multiple types (Sick, Personal, Vacation)
  ✓ Admin approval/rejection workflow with remarks capability
  ✓ Automatic prevention of overlapping leave applications
  ✓ Beautiful, responsive user interface with Bootstrap 5
  ✓ Role-based access control (Employee/Admin)
  ✓ Complete RESTful API for integrations
  ✓ Professional UI theme with gradient colors and smooth animations
  ✓ Database backup and sample data included
  ✓ Mobile-friendly design
  ✓ Form validation and error handling

TECHNOLOGY STACK:
  • Framework: Laravel 11
  • Database: MySQL
  • Frontend: Bootstrap 5, Custom CSS, Font Awesome Icons
  • PHP Version: 8.2+
  • API: RESTful with Sanctum authentication

PROJECT STRUCTURE:
  • app/Models/ - Database models (User, Leave)
  • app/Http/Controllers/ - Business logic (LeaveController, AuthController)
  • app/Http/Middleware/ - Authentication middleware (AdminMiddleware)
  • database/migrations/ - Database schema
  • database/seeders/ - Sample data
  • resources/views/ - User interface templates
  • routes/ - API and web routes
  • database_export.sql - Complete database backup

2. Go to this URL: http://127.0.0.1:8000

STEP 4: FOR EMPLOYEES - APPLY FOR LEAVE
================================================================================

After logging in with an EMPLOYEE account, follow these steps:

1. You will see the Leave Management Dashboard with:
   - Summary cards showing Pending, Approved, and Rejected leaves count
   - A table with all your leave requests
   - "Apply for Leave" button at the top right

2. Click "Apply for Leave" button (top right corner)

3. You will see the Leave Application Form with these fields:
   - Leave Type: Choose from (Sick Leave, Personal Leave, Vacation, Other)
   - Start Date: Click and pick your leave start date
   - End Date: Click and pick your leave end date
   - Reason: Write why you need the leave (minimum 10 characters)

4. Important: The system automatically calculates the number of days

5. Fill all fields with valid information:
   Example:
   - Leave Type: Vacation
   - Start Date: 2026-09-05
   - End Date: 2026-09-08
   - Reason: Family vacation to visit relatives

6. Click "Submit Application" button

7. SUCCESS! Your leave request will be submitted with PENDING status

8. You will see a success message: "Leave application submitted successfully!"

9. You can now see your application in the leaves list with "Pending" badge


STEP 5: FOR EMPLOYEES - EDIT YOUR PENDING LEAVE
================================================================================

To modify a leave application that is still PENDING:

1. Go to "My Leaves" page (click "My Leaves" in navigation)

2. Find your pending leave request (status shows "Pending" badge)

3. Click the "Edit" button (pencil icon) for that leave

4. Modify any field (dates, type, reason)

5. Click "Update Request" button

6. Your changes will be saved

NOTE: You can ONLY edit leaves with PENDING status. Once approved or rejected, 
you cannot modify them.


STEP 6: FOR EMPLOYEES - DELETE YOUR PENDING LEAVE
================================================================================

To delete a leave application that is still PENDING:

1. Go to "My Leaves" page

2. Find your pending leave request

3. Click the "Delete" button (trash icon)

4. Confirm the deletion when asked

5. Your leave request will be permanently deleted

NOTE: You can ONLY delete leaves with PENDING status.


STEP 7: FOR EMPLOYEES - VIEW LEAVE DETAILS
================================================================================

To view full details of any leave request:

1. Go to "My Leaves" page

2. Click the "View" button (eye icon) on any leave

3. You will see complete information:
   - Employee name and email
   - Leave type with badge
   - Start and end dates
   - Total number of days
   - Reason for leave
   - Current status (Pending/Approved/Rejected)
   - Admin's remarks (if rejected)
   - Who approved/rejected and when

4. Click "Back to Leaves" to return to the list


STEP 8: FOR ADMINS - VIEW ALL LEAVE REQUESTS
================================================================================

After logging in with ADMIN account:

1. You will see the Leave Management Dashboard with:
   - All employee leave requests (not just your own)
   - Summary cards showing Pending, Approved, Rejected counts
   - Complete leave table with employee details

2. The table shows:
   - Employee name and email
   - Leave type
   - Date range (Start to End)
   - Number of days
   - Current status (Pending/Approved/Rejected)
   - Quick action buttons

3. You can scroll through the list and see all applications


STEP 9: FOR ADMINS - APPROVE A LEAVE REQUEST
================================================================================

To approve an employee's leave request:

1. Go to "My Leaves" page

2. Look for leaves with "Pending" status badge (yellow/orange)

3. Click on the leave you want to approve

4. You will see full details including:
   - Employee information
   - Leave dates and reason
   - "Admin Actions" section at the bottom

5. In the "Admin Actions" section, click "Approve Leave" button (green)

6. SUCCESS! The leave status changes to "Approved" (green badge)

7. The employee's name is recorded as the approver

8. The approval date and time are recorded


STEP 10: FOR ADMINS - REJECT A LEAVE REQUEST
================================================================================

To reject an employee's leave request:

1. Go to "My Leaves" page

2. Find the pending leave you want to reject

3. Click on the leave to view details

4. In the "Admin Actions" section, click "Reject Leave" button (red)

5. A popup modal will appear with:
   - Title "Reject Leave Request"
   - Text field for "Remarks (Required)"

6. Write your reason for rejection in the remarks field:
   Example: "Cannot approve due to insufficient notice period. 
            Please reapply with 10 days advance notice."

7. Click "Reject" button in the modal

8. SUCCESS! The leave status changes to "Rejected" (red badge)

9. Your name is recorded as who rejected it

10. The employee will see your remarks when viewing the leave


STEP 11: FOR ADMINS - FILTER AND SEARCH
================================================================================

Current features available:

1. View all leaves for all employees

2. Employees can only see their own leaves

3. Pagination: If there are many leaves, they are split into pages
   - Use page numbers at the bottom to navigate

4. Status indicators: Quickly see which leaves are Pending/Approved/Rejected
   - Yellow badge = Pending
   - Green badge = Approved
   - Red badge = Rejected


STEP 12: OVERLAPPING LEAVE PREVENTION (AUTOMATIC)
================================================================================

The system automatically prevents overlapping leave applications:

EXAMPLE:
- If you already have approved leave from Aug 5-10
- And you try to apply for Aug 8-12
- System will show error: "You already have a leave request for these dates."

SCENARIOS BLOCKED:
  ✓ Leave starts during an existing leave
  ✓ Leave ends during an existing leave
  ✓ Leave completely covers an existing leave
  ✓ Leave partially overlaps with existing leave

SCENARIOS ALLOWED:
  ✓ Leaves separated by at least 1 day (Aug 5-8 and Aug 9-12)
  ✓ Rejected leaves don't block new applications
  ✓ You can re-apply for different dates after rejection

HOW IT WORKS:
1. When you fill the form, just submit it
2. System automatically checks for conflicts
3. If conflict found, you see error message
4. Choose different dates and try again


STEP 13: LOGOUT FROM THE SYSTEM
================================================================================

To logout and end your session:

1. Look at the top right corner of the page

2. Click on your name (shows "Welcome, John Doe" or similar)

3. A dropdown menu appears

4. Click "Logout" option

5. You will be logged out and redirected to login page

6. Your session is now ended


STEP 14: STOP THE SERVER
================================================================================

When you are done using the application:

1. Go to the Command Prompt/PowerShell window where you started the server

2. Press Ctrl + C (hold Ctrl and press C)

3. Type "Y" and press Enter to confirm

4. The server will stop

5. You can now close the command prompt window


TROUBLESHOOTING & COMMON ISSUES
================================================================================

ISSUE: "Route [login] not defined" error
SOLUTION: Refresh the browser or clear cache (Ctrl + Shift + Delete)

ISSUE: Cannot login with credentials
SOLUTION: Check that you're using the exact email and password provided above

ISSUE: "Overlapping leave" error when applying
SOLUTION: Choose different dates that don't conflict with existing leaves

ISSUE: Cannot edit or delete approved/rejected leaves
SOLUTION: This is by design - only PENDING leaves can be modified

ISSUE: Server shows "Connection refused"
SOLUTION: Make sure you started the server with "php artisan serve"

ISSUE: Blank page or slow loading
SOLUTION: Refresh the browser or wait a few seconds for page to load

ISSUE: Database errors
SOLUTION: Make sure MySQL server is running (start XAMPP MySQL)

API ENDPOINTS (For Developers)
================================================================================

BASE URL: http://127.0.0.1:8000/api

AUTHENTICATION: Use Bearer tokens (Bearer token required in header)

AVAILABLE ENDPOINTS:

GET /api/health
  - Health check endpoint (no auth required)

GET /api/leaves
  - Get current user's leaves

POST /api/leaves
  - Create new leave
  - Body: { start_date, end_date, type, reason }

GET /api/admin/leaves
  - Get all leaves (admin only)

GET /api/admin/leaves/pending
  - Get pending leaves (admin only)

POST /api/admin/leaves/{id}/approve
  - Approve a leave (admin only)

POST /api/admin/leaves/{id}/reject
  - Reject a leave (admin only)
  - Body: { remarks }
