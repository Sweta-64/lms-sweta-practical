TESTING SCENARIOS FOR REVIEWER
================================================================================

SCENARIO 1: Employee Workflow
---
1. Login as john@lms.com
2. Click "Apply for Leave"
3. Fill form:
   - Type: Vacation
   - Start: Any future date
   - End: 3 days later
   - Reason: "Family vacation"
4. Submit and verify success message
5. See leave in "My Leaves" with PENDING status
6. Edit the leave (change dates)
7. Verify changes saved
8. Try to apply again for same dates → Should see error

SCENARIO 2: Overlapping Prevention
---
1. Employee already has leave Aug 5-10
2. Try to apply for Aug 7-12
3. System should show: "You already have a leave request for these dates"
4. Change dates to Aug 11-15 and apply successfully

SCENARIO 3: Admin Workflow
---
1. Login as admin@lms.com
2. Go to "My Leaves" to see all employee requests
3. Click on PENDING leave
4. Click "Approve Leave"
5. Verify status changes to APPROVED
6. Click on another pending leave
7. Click "Reject Leave"
8. Add remark: "Insufficient notice"
9. Verify status changes to REJECTED with remark

SCENARIO 4: Role-Based Access
---
1. Login as employee
2. Cannot see "Approve" button (only admins can)
3. Logout and login as admin
4. Can see and use approve/reject buttons
